## About

CSAI student at IE University, second year. I mostly work on embedded systems, simulation, and ML, usually all three in the same project: a PCB and firmware on one end, a model or dashboard on the other.

Interested in defense, robotics, and anything with a hardware layer that's actually hard to build.

## Projects

| Project                                                                     | Description                                                                                                                                                                              |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **[AEGIS](https://github.com/YousefAliAicha/aegis-embedded-system)**        | Rotating ultrasonic radar on an ESP32-S3. Streams telemetry over WebSocket to a dashboard served straight from the board's flash. Custom KiCad PCB.                                      |
| **[SENTINEL](https://github.com/YousefAliAicha/sentinel-arduino-firmware)** | Adaptive traffic-light FSM on an ATmega328P. Pedestrian preemption, night-mode vehicle detection, custom PCB with a hand-drawn footprint.                                                |
| **[Raycaster-Engine](https://github.com/YousefAliAicha/Raycaster-Engine)**  | 2.5D raycaster in pure Python and NumPy. DDA ray marching, textured floors and walls, z-buffer sprite occlusion, fog.                                                                    |
| **[Splice-Engine](https://github.com/YousefAliAicha/splice-engine)**        | Movie recommender trained on MovieLens. Routes users through cold-start, KNN, or a stacked LightGBM ensemble depending on rating history. Streamlit dashboard with a live feedback loop. |
